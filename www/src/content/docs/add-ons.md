---
title: Add-ons
description: Optional libraries the CLI can add, and why the base has none.
---

The base game stays unopinionated: it uses only what the stack needs to run (Flamework, React, `@rbxts/services`, `@rbxts/t`) and leaves libraries for data, state and the rest to you.

Like create-t3-app, the CLI will offer the most popular choice for each of these as an add-on, or none. Each add-on arrives wired in, with its own tests and notes in `AGENTS.md`. Add-ons aren't available yet.

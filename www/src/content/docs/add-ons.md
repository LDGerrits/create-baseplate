---
title: Add-ons
description: Optional libraries the CLI can add, and why the base has none.
---

The base game stays unopinionated: it brings Flamework and React with a few small helpers they work well with (`@rbxts/services`, `@rbxts/t`, `@rbxts/object-utils`, `@rbxts/pretty-react-hooks` with Ripple, and UI Labs for stories), and leaves libraries for data, state and the rest to you.

Like create-t3-app, the CLI will offer the most popular choice for each of these as an add-on, or none. Each add-on arrives wired in, with its own tests and notes in `AGENTS.md`. Add-ons aren't available yet.

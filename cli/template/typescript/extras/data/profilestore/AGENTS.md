## Player data

`PlayerDataService` (`src/game/player-data/server/`) loads each player's saved data with ProfileStore (`@rbxts/profile-store`) when they join, and saves it when they leave. Other services read it with `get(userId)` and change it with `update(userId, (data) => newData)`, getting the service through their constructor. Add saved fields to `PlayerData` and `DEFAULT_PLAYER_DATA` in `player-data.ts`; `Reconcile` gives players who saved before the new defaults. If another server takes a player's session, the player is kicked to rejoin, so their changes aren't lost. Studio saves to a mock store, forgotten when the server stops, and specs give the service their own (`player-data-service.spec.ts`).

## Player data

`PlayerDataService` (`src/game/playerdata/server/`) loads each player's saved data with ProfileStore (`ServerScriptService.ServerPackages.ProfileStore`) when they join, and saves it when they leave. Other services require it, read a player's data with `PlayerDataService.get(userId)` and change it with `PlayerDataService.update(userId, function(data) ... end)`, which saves what the function returns: a changed copy. `table.clone` copies one level, so also copy each nested table you change: `copy.inventory = table.clone(data.inventory)`. Add saved fields to the `PlayerData` type and `DEFAULT` in `PlayerData.luau`; `Reconcile` gives players who saved before the new defaults. If another server takes a player's session, the player is kicked to rejoin, so their changes aren't lost. Studio saves to a mock store, forgotten when the server stops, and specs give the service their own (`PlayerDataService.spec.luau`).
